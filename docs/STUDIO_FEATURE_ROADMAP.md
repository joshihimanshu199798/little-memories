# Studio Feature Roadmap

## Studio navigation
- [x] Add Studio as a new bottom navigation destination.
- [x] Keep existing Home, Albums and Settings destinations.
- [x] Preserve the existing photo editor entry point.
- [x] Add Family Memories and Film Lab entry points.

## Family Memories
- [x] Local chronological photo timeline grouped by month.
- [x] On This Day matching by month/day from earlier years.
- [x] User-created milestones with manually selected dates.
- [x] Persist milestones locally.
- [ ] Attach selected photos and captions to milestones.
- [ ] Monthly highlight collections.
- [ ] Memory calendar.
- [ ] Slideshow maker.
- [ ] Memory book templates and PDF export.
- [ ] Family albums and user-controlled sharing.

## Film Lab
- [x] Initial film-inspired preset collection.
- [x] Adjustable intensity.
- [x] Preview-resolution rendering.
- [x] Full-resolution JPEG export as a new photo.
- [x] Preserve original photo.
- [ ] Add actual grain, bloom, halation and light-leak effect controls.
- [ ] Add generated thumbnails for each preset.
- [ ] Add custom preset save and favorites.
- [ ] Add before/after comparison.
- [ ] Add film border and date-stamp options.

## Remaining Studio modules
- [ ] Compression Studio: quality, dimensions, formats, batch compression and size comparison.
- [ ] Collage Studio: 2–20 photos, layouts, drag/swap, spacing, backgrounds and export.
- [ ] Batch Editor: recipe copy/paste, batch filters, resize, convert and export.
- [ ] Selective editing: masks, brush, erase, feather, inversion and local adjustments.
- [ ] Portrait retouching: natural smoothing, blemish correction and background blur.
- [ ] AI Studio: offline segmentation and secure optional online inpainting/restoration.
- [ ] RAW Editor: genuine DNG decoding and native RAW development pipeline.
- [ ] Color Lab: HSL, curves, color wheels and LUT support.

## Quality gates
- [ ] Flutter analyze.
- [ ] Flutter tests.
- [ ] Build release APK.
- [ ] Install and test on physical Android device.
- [ ] Verify exports open and original files remain unchanged.
